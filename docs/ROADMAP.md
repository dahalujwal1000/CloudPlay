# Product Roadmap

## V0 — Prototype
PC capture → NVENC → WebRTC → Android video.

## V0.2 — Interactive
Touch/controller input.

## V0.3 — Game lifecycle
Game profiles and launch/monitor/stop.

## V0.4 — Secure
Pairing, authentication, credential storage.

## V0.5 — Remote
Signaling, STUN/TURN, Internet connectivity.

## V0.6 — Adaptive
Bitrate adaptation, telemetry, reconnect.

## V0.9 — Release Candidate
Compatibility, long-session testing, installer, diagnostics.

## V1.0
Stable personal cloud-gaming client.

## Future
Only after V1 stability:
- HEVC
- AV1
- HDR
- higher resolutions
- iOS
- multi-host
- richer controller profiles

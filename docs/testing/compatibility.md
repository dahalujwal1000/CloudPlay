# Compatibility Matrix

## Windows
- Windows 11 current supported release
- NVIDIA RTX 3050 6 GB class
- current supported NVIDIA driver

## Android
Test at minimum:
- one mid-range device
- one flagship device
- one older supported device

Record:
- Android version
- SoC/GPU
- hardware H.264 decoder behavior
- refresh rate
- Wi-Fi capability

Compatibility must be based on actual test results, not assumptions.
